# Team Roles

Each member should contribute technically and own one PoC. The roles below are horizontal responsibilities, not exclusive job boundaries.

## Role 1 - Architecture and Integration Lead
Primary responsibilities:
- overall technical architecture
- common interfaces/adapters
- integration across PoCs
- repository structure and technical decisions


## Role 2 - Literature and Survey Lead
Primary responsibilities:
- literature search process
- paper matrix
- system survey coordination
- inclusion/exclusion documentation
- citation hygiene

## Role 3 - Infrastructure and Model-Serving Lead
Primary responsibilities:
- Docker/Compose
- local model serving
- PostgreSQL and shared services
- hardware/resource documentation
- reproducibility

## Role 4 - Benchmark and Evaluation Lead
Primary responsibilities:
- benchmark design
- task definitions
- expected outputs
- metrics
- repeated runs
- result collection and analysis

## Role 5 - Security Lead
Primary responsibilities:
- NIST/BSI/OWASP mapping
- threat model
- prompt-injection tests
- tool permission tests
- isolation and auditability

## PoC ownership
Each team member owns one selected agentic AI system after the survey. Final systems are not fixed yet.

## Team rule
Important methodology and architecture decisions should be recorded in GitHub, not only in WhatsApp/Teams.
