# Architecture Decision Records

Use this folder for important decisions that the team may need to understand months later.

Suggested format:

# ADR-XXX: Decision title

## Status
Proposed / Accepted / Superseded

## Context
What problem are we deciding?

## Options
What alternatives were considered?

## Decision
What did we choose?

## Rationale
Why?

## Consequences
What becomes easier/harder because of the decision?

Potential early ADRs:
- ADR-001 repository/project workflow
- ADR-002 database choice
- ADR-003 model-serving choice
- ADR-004 system-selection methodology
- ADR-005 benchmark adapter architecture
