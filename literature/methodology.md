# Literature Review Methodology

## Goal

Build the academic and standards foundation for:
- agentic AI definitions
- self-hosting
- agent architectures
- tool use and memory
- security and trustworthiness
- evaluation
- digital sovereignty

## Starting sources

The course brief already points to:
- Gohil et al. - agentic AI foundations/taxonomy
- Sapkota et al. - AI agents vs agentic AI taxonomy
- NIST AI security/adversarial ML material
- BSI AI material

The team should expand beyond these starting sources.

## Suggested databases

- Google Scholar
- IEEE Xplore
- ACM Digital Library
- SpringerLink
- ScienceDirect

## Suggested fields for the literature matrix

- citation
- year
- source type
- research question
- definition of agent/agentic AI
- architecture concepts
- self-hosting relevance
- security relevance
- evaluation method
- limitations
- key finding
- how this source is used in our project

## Review discipline

Record:
- search source
- search query
- date
- number of results considered
- reasons for excluding important-looking papers

A lightweight systematic/scoping-review process is preferred over an undocumented reading list.

## Output

Working notes belong in this repository; the final academic synthesis belongs in the scientific report.
