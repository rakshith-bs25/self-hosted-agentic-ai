# FOSS Agentic AI System Survey Methodology

## Purpose

Identify the current landscape of self-hostable FOSS agentic AI systems and select a representative subset for experimental evaluation.

## Candidate sources

Search:
- GitHub
- official project websites
- official documentation
- Hugging Face
- relevant academic papers
- reputable technical references

## Process

1. Define what counts as an agentic AI system for this project.
2. Search the sources above using documented queries/keywords.
3. Record every plausible candidate in the candidate matrix.
4. Remove duplicates.
5. Apply mandatory inclusion/exclusion criteria.
6. Compare remaining candidates on secondary parameters.
7. Select a representative subset for PoCs.
8. Record the complete rationale.

## Suggested search terms

- open source agentic AI
- self-hosted AI agent
- local AI agent framework
- FOSS multi-agent framework
- local LLM agent framework
- on-premise agentic AI
- open source autonomous agent
- open source MCP agent

## Candidate pool size

There is no fixed requirement of 15 or 20 systems. The team should aim for broad enough coverage to justify the selection. A practical target may be roughly 10-20 credible candidates, depending on what the search finds.

## Output

The survey should produce:
- candidate-system matrix
- inclusion/exclusion record
- selected-system rationale
- report section describing the methodology and findings
